## COURSE DESCRIPTION:
This class is a 'hands on' introduction to methods and tools for machine learning for biomedical research. Topics to be included will be model training and validation, regression and regularization, unsupervised learning and clustering, dimension reduction, supervised learning and classification (support vector machines, decision trees, random forests, and gradient boosting), neural networks and deep learning, and modern AI including generative, agentic, and federated approaches. We will generally describe the history, theory, and methods for each approach, discuss appropriate situations for application, and practice and apply computer code for applying each method. The goal of this course is to establish a fundamental understanding and working knowledge of machine learning tools, with less emphasis on mathematical rigor than other courses on campus (e.g., 14:332:443 Machine Learning for Engineers, Department of Electrical and Computer Engineering, Rutgers School of Engineering). This course is also distinct in its application on biomedical data--examples come from a variety of low and high dimensional research problems, such as epidemiology, clinical trials, biomarker discovery, and -omics data analysis. The course will be taught in R, and students will be expected to use R and GitHub throughout this course. **New this semester:** we will also be adding companion guides and code in Python, so students can follow along in either language.


## COURSE OBJECTIVES:
Students who take this course will: 

1. Become familiar with the most common methods for machine learning in biomedical research
2. Understand (generally) the theory and methods behind common methods for machine learning
3. Know the appropriate time and situations to apply each machine learning method
4. Learn the principles of model training, cross-validation, and validation
5. Gain hands on experience in applying a variety of machine learning tools to biomedical data
6. Understand the current landscape of AI (predictive, generative, and agentic) and its uses and limitations in biomedical research

## COURSE TOPICS AND OUTLINE (BY WEEK)
The course will be conducted two days per week (Mondays and Wednesdays), two hours each. Tentative course start date is October 14, 2026, and the end date will be December 16, 2026.

Model training and validation (Oct 14, 19)

* Course introduction
* Evaluation metrics and cross-validation
* The bootstrap
* Application: clinical trials and drug testing 

Tools for machine learning (Oct 21)

* The caret package in R
* The h2o package and AutoML
* Application: biomarker development

Regression and regularization (Oct 26, 28)

* Multiple regression
* Generalized linear models
* Ridge regression, LASSO, ElasticNet
* Application: diabetes risk prediction in NHANES (CDC National Health and Nutrition Examination Survey)

Unsupervised learning and dimension reduction (Nov 2, 4)

* Hierarchical and K-means clustering
* Visualization: boxplots, heatmaps, etc 
* Singular value decomposition, principal components
* Advanced reduction methods (NMF, t-SNE, UMAP)
* Application: gene expression and single cell transcriptomics

Support vector machines (Nov 9, 11)

* Linear and kernel SVMs
* Application: TB gene expression biomarkers

Trees and ensemble methods (Nov 16, 18, 23)

* Regression/decision trees
* Random forests
* Gradient boosting (GBM, XGBoost)
* Application: genome variation analysis
* Nov 16 and 18: pre-recorded lectures (no live session)

Neural networks and deep learning (Nov 25, 30)

* Feed-forward and recurrent networks
* Convolutional neural networks
* Deep learning
* Application: biomarker development (revisited)

Modern AI in biomedicine (Dec 2, 7, 9)

* The evolution of AI: predictive, generative, and agentic
* Generative AI, foundation models, and large language models (LLMs)
* Agentic AI and other AI applications
* Federated learning

Final project presentations (Dec 14, 16)
